# my-first-page

我的第一个网页项目：一个纯静态页面，用来验证 HTML / CSS / JavaScript 都能正常工作。

## 这个网页能做什么

- 显示一个计数器
- 点 `+1` 数字加一，点 `-1` 数字减一，点「归零」回到 0
- 手机和电脑上打开都能正常显示（做了响应式适配）

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面的骨架，浏览器打开的就是它 |
| `style.css` | 页面的样子：颜色、字号、圆角、按钮样式 |
| `app.js` | 页面的行为：按钮点下去之后数字怎么变化 |

## 怎么在本地打开

直接双击 `index.html`，会用默认浏览器打开。不需要安装任何东西，也不需要启动服务器。

## 技术说明

- 纯静态：没有使用任何框架（React / Vue 等），也没有引用任何外部 CDN
- 三个文件都是最基础的 HTML / CSS / 原生 JavaScript
- 计数会尝试存进浏览器的 localStorage，换页面刷新后数字还在；如果浏览器不允许（比如某些情况下用 `file://` 直接打开），就会自动退回从 0 开始，不会报错
